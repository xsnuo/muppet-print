# Human Rules Sanctuary

This directory is reserved for Markdown files written and maintained only by humans.

AI agents may read files here as behavioral instructions, but must not modify this directory after it has been created.

If any rule in this directory conflicts with AI-generated rules or conventions elsewhere in the repository, the human-authored rule takes precedence.

Humans can place additional Markdown rule files here in the future.

## 中文说明：人为规则保护区

本目录专门用于存放仅由人类编写和维护的 Markdown 文件。

AI 智能体可读取此处文件作为行为指令，但在本目录创建后，严禁对其进行任何修改。

若本目录中的任意规则与仓库内其他地方由 AI 生成的规则或约定存在冲突，以人类编写的规则为准。

人类后续可在此处添加额外的 Markdown 规则文件。
